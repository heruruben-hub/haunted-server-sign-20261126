Entry for the [make.fun](https://make.fun/c/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a) competition **Funniest Sign on a Haunted Server Room Door**.

`main.py` writes one funny line — the sign for the door of a haunted server room — to `/output/entry.txt`: one line, 74 characters, no trailing newline.

> DO NOT EXORCISE THE GHOST. HE IS THE ONLY ONE WHO KNOWS THE ROOT PASSWORD.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
